# frontend

The frontend of the [Pint](../README.md) project.

## Setup

### 1. Install dependencies

```bash
bun install
```

## Testing

### Run Unit Tests with [Vitest](https://vitest.dev/)

```bash
bun test:unit
```

## Formatting and linting

The frontend uses Oxc's formatter and linter:

```bash
# Format source files
bun format

# Check formatting without changing files
bun format:check

# Run Oxlint
bun lint
```
